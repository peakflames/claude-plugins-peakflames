## 1. System Overview

`ledger` is a personal-budget command-line tool. One person runs it in a terminal to import
bank CSV exports into a local `ledger.json` file and report on spending. It is a single Node.js
process with no server, no network access and no deployment.

---

## 2. Tech Stack

| Layer | Technology | Purpose |
|---|---|---|
| Language / runtime | JavaScript (ES modules) on Node.js 22+ | The CLI |
| Tests | `node:test` + `node:assert` | Automated checks |
| Storage | `ledger.json` in the current directory | The ledger |
| Dependencies | None | Standard library only |
