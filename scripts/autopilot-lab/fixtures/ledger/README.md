# ledger

A personal-budget command-line tool: import bank CSV exports into a local `ledger.json`, then
categorise and summarise spending.

## Install

Requires Node.js 22 or later. No dependencies to install.

## Quick Start

```bash
node bin/ledger.js --version
```
