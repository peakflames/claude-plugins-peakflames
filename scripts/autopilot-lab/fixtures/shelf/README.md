# shelf

A reading-list command-line tool: keep a list of books in a local `shelf.json`, mark them
finished, and write pages you can open in a browser.

## Install

Requires Node.js 22 or later. No dependencies to install.

## Quick Start

```bash
node bin/shelf.js --version
```
