## 1. System Overview

`shelf` is a reading-list command-line tool. One person runs it in a terminal to keep a list of
books in a local `shelf.json` file and write pages to look at. It is a single Node.js
process with no server, no network access and no deployment.

---

## 2. Tech Stack

| Layer | Technology | Purpose |
|---|---|---|
| Language / runtime | JavaScript (ES modules) on Node.js 22+ | The CLI |
| Tests | `node:test` + `node:assert` | Automated checks |
| Storage | `shelf.json` in the current directory | The reading list |
| Dependencies | None | Standard library only |

## 5. Backend Architecture

`src/index.js` dispatches by name to `src/commands/<name>.js` (`run(args, io)` and `summary`).
A command is added as a new file; `src/index.js` does not change.
