# Peak Workflow for Everyone (video source)

Source for a 5:20 narrated explainer video: the same app built twice, once by plain vibe coding and once with Peak Workflow, compared head to head on four traits (systematic, iterative, human-steered, and backed by evidence).

Everything here is independent of any slide tool, visual style, recorder, or voice. Build the 11 slides in any style, narrate the script with any voice, and change slides in the pause before each paragraph.

| File | What it is |
|---|---|
| `storyboard.md` | Each slide's on-screen content next to its verbatim script, plus pacing from the reference cut and how to read the delivery tags |
| `claims-trace.md` | The source for every claim in the video. One line on slide 6 is dramatized and marked there |
| `shots/` | The two app screenshots shown on slides 3 and 9 |

## Not committed

The rendered video, the narration audio, and the reference deck and recording scripts stay out of the repo, because a marketplace install clones this repository. The demo evidence cited in `claims-trace.md` (`vibe-build/`, `peak-build/`) lives in the original working session, not here.
